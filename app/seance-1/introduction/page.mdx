# Introduction aux bases JavaScript - Séance 1

Bienvenue dans le cours **R4A10 - Compléments Web** ! Cette première séance pose les fondations essentielles pour maîtriser React. Avant de plonger dans React, vous devez comprendre le langage sur lequel il est construit : **JavaScript moderne**.

## Pourquoi JavaScript avant React ?

React est une **bibliothèque JavaScript**. Tout ce que vous écrirez en React sera du JavaScript déguisé. Comprendre JavaScript, c'est comprendre React.

```jsx
// Ce code React...
function Welcome({ name }) {
  return <h1>Bonjour {name} !</h1>;
}

// ...n'est que du JavaScript moderne
const Welcome = ({ name }) => {
  return React.createElement('h1', null, `Bonjour ${name} !`);
};
```

<Callout type="info" title="Ce que vous allez apprendre">
À la fin de cette séance, vous serez capable de :

- Comprendre les fondamentaux du web (HTML, CSS, DOM)
- Utiliser la syntaxe JavaScript moderne (ES6+)
- Manipuler des tableaux avec `.map()`, `.filter()`, `.reduce()`
- Maîtriser la destructuration et le spread operator
- Écrire du code asynchrone avec les Promises
- Utiliser les modules ES6
- Collaborer efficacement avec l'IA pour coder
</Callout>

## Présentation du cours

Ce cours se compose de **5 séances de 3h30**, progressant du JavaScript fondamental aux concepts avancés de React.

**Plan des séances :**

1. **Séance 1 - Bases JavaScript** (cette séance)
   - Rappels HTML/CSS/DOM
   - JavaScript moderne ES6+

2. **Séance 2 - React Fundamentals**
   - JSX, Composants, Props
   - Listes et rendu conditionnel

3. **Séance 3 - Interactivité & Formulaires**
   - useState, événements
   - Formulaires contrôlés et validation

4. **Séance 4 - Effects & Routing**
   - useEffect, data fetching
   - React Router

5. **Séance 5 - Projet & IA**
   - Workflow IA
   - Best practices et déploiement
