# Environnement de développement

Avant de commencer avec React, il faut comprendre les outils qui vont nous permettre de développer. Cette page explique **pourquoi** et **comment** installer l'environnement nécessaire.

## Pourquoi avons-nous besoin d'outils ?

React est une bibliothèque JavaScript, mais pour l'utiliser efficacement, nous avons besoin de plusieurs outils :

1. **Exécuter JavaScript en dehors du navigateur** (Node.js)
2. **Installer des bibliothèques** comme React (npm/pnpm/yarn)
3. **Transformer notre code** pour qu'il fonctionne dans tous les navigateurs (Vite/Webpack)
4. **Tester notre code** pendant le développement (serveur de dev)

<Callout type="info" title="L'écosystème JavaScript moderne">
Contrairement à HTML/CSS qu'on peut écrire directement, le développement JavaScript moderne utilise des **outils de build** pour :

- Utiliser des fonctionnalités récentes (JSX, modules ES6)
- Optimiser les performances
- Gérer des dizaines de bibliothèques
- Avoir un serveur de développement avec rechargement automatique
</Callout>

## Node.js : JavaScript côté serveur

### Qu'est-ce que Node.js ?

**Node.js** est un **environnement d'exécution JavaScript** qui permet de faire tourner du code JavaScript en dehors du navigateur.

```
┌──────────────────┐      ┌──────────────────┐
│   JavaScript     │      │   JavaScript     │
│   dans le        │      │   avec           │
│   navigateur     │      │   Node.js        │
│                  │      │                  │
│   • Sites web    │      │   • Serveurs     │
│   • Interactivité│      │   • Outils CLI   │
│                  │      │   • Scripts      │
└──────────────────┘      └──────────────────┘
```

### Pourquoi Node.js pour React ?

<Callout type="warning" title="Attention : Node.js n'est PAS obligatoire en production">
Node.js est utilisé **pendant le développement**, pas en production :

- ✅ Pour installer React et ses dépendances
- ✅ Pour lancer le serveur de développement
- ✅ Pour compiler/transformer le code JSX
- ✅ Pour créer le build de production

❌ Le code React final tourne **dans le navigateur**, pas sur Node.js
</Callout>

### Installer Node.js

**Méthode recommandée :**

1. Télécharger depuis [nodejs.org](https://nodejs.org/)
2. Choisir la version **LTS** (Long Term Support)
3. Suivre l'installateur (accepter les options par défaut)

**Versions Node.js :**
- **LTS (recommandé)** : Version stable pour la production
- **Current** : Dernières fonctionnalités (peut être instable)

<Callout type="tip" title="Quelle version ?">
Pour ce cours, n'importe quelle version récente (18.x ou supérieure) fonctionne.

```bash
# Vérifier la version installée
node --version
# Exemple de sortie : v20.10.0
```
</Callout>

### Alternatives à Node.js

Il existe d'autres runtimes JavaScript plus modernes :

**Bun** 🥟
- Runtime ultra-rapide (écrit en Zig)
- Compatible Node.js
- Inclut un bundler et un gestionnaire de paquets
- [bun.sh](https://bun.sh/)

**Deno** 🦕
- Créé par le créateur de Node.js
- Sécurisé par défaut
- Support TypeScript natif
- [deno.land](https://deno.land/)

<Callout type="info" title="Pour ce cours">
Nous utilisons **Node.js** car c'est le standard de l'industrie et le mieux supporté. Mais Bun est une excellente alternative si vous voulez expérimenter !
</Callout>

## npm : Le gestionnaire de paquets

### Qu'est-ce que npm ?

**npm** (Node Package Manager) est installé automatiquement avec Node.js. C'est un outil qui permet de :

- **Installer des bibliothèques** (React, React Router, etc.)
- **Gérer les dépendances** d'un projet
- **Exécuter des scripts** (lancer le serveur, build, tests)

```bash
# Installer une bibliothèque
npm install react

# Lancer un script défini dans package.json
npm run dev

# Créer un nouveau projet
npm create vite@latest
```

### Comment fonctionne npm ?

Chaque projet a un fichier `package.json` qui liste :

```json
{
  "name": "mon-app",
  "version": "1.0.0",
  "dependencies": {
    "react": "^18.2.0",
    "react-dom": "^18.2.0"
  },
  "scripts": {
    "dev": "vite",
    "build": "vite build"
  }
}
```

**Quand vous faites `npm install` :**
1. npm lit `package.json`
2. Télécharge toutes les bibliothèques listées
3. Les place dans un dossier `node_modules/`
4. Crée un fichier `package-lock.json` (verrouille les versions exactes)

<Callout type="warning" title="node_modules est énorme !">
Le dossier `node_modules/` peut contenir des milliers de fichiers et peser plusieurs centaines de Mo.

**C'est normal !** Mais ne le committez **jamais** sur Git (utilisez `.gitignore`).

Pour recréer `node_modules/` sur un autre ordinateur :
```bash
npm install  # Réinstalle tout depuis package.json
```
</Callout>

### Vérifier que npm fonctionne

```bash
# Version de npm
npm --version
# Exemple : 10.2.3

# Aide
npm help

# Liste des paquets installés globalement
npm list -g --depth=0
```

## Alternatives à npm

Il existe plusieurs gestionnaires de paquets, tous compatibles avec l'écosystème JavaScript :

### pnpm - Performant et économe 🚀

**Avantages :**
- Beaucoup plus rapide que npm
- Économise de l'espace disque (stockage partagé)
- Gestion stricte des dépendances

```bash
# Installer pnpm
npm install -g pnpm

# Utilisation (identique à npm)
pnpm install
pnpm add react
pnpm run dev
```

<Callout type="tip" title="pnpm est recommandé !">
Si vous travaillez sur plusieurs projets, **pnpm** peut vous faire gagner beaucoup d'espace disque et de temps.

Site : [pnpm.io](https://pnpm.io/)
</Callout>

### Yarn - L'alternative historique

Créé par Facebook, très populaire mais moins rapide que pnpm.

```bash
# Installer Yarn
npm install -g yarn

# Utilisation
yarn install
yarn add react
yarn dev
```

### Bun - Le plus rapide (nouveau)

Bun inclut son propre gestionnaire de paquets ultra-rapide.

```bash
# Installation avec Bun
bun install
bun add react
bun run dev
```

### Comparaison rapide

| Outil  | Vitesse       | Espace disque | Popularité |
|--------|---------------|---------------|------------|
| npm    | Moyen         | ⚠️ Élevé      | ⭐⭐⭐⭐⭐   |
| pnpm   | 🚀 Rapide     | ✅ Économe    | ⭐⭐⭐⭐     |
| Yarn   | Rapide        | Moyen         | ⭐⭐⭐⭐     |
| Bun    | 🚀🚀 Ultra    | ✅ Économe    | ⭐⭐⭐       |

<Callout type="info" title="Pour ce cours">
Tous les exemples utilisent **npm** car c'est installé par défaut avec Node.js.

Mais vous pouvez utiliser **pnpm** ou **bun** si vous préférez - les commandes sont identiques !
</Callout>

## Commandes essentielles npm

Voici les commandes que vous utiliserez le plus souvent :

### Installation de paquets

```bash
# Installer toutes les dépendances d'un projet
npm install
# Raccourci : npm i

# Installer une bibliothèque
npm install react
npm install react-router-dom

# Installer en dépendance de développement (pas nécessaire en production)
npm install --save-dev eslint
# Raccourci : npm i -D eslint

# Installer globalement (accessible partout sur votre machine)
npm install -g create-vite
```

### Exécution de scripts

```bash
# Lancer un script défini dans package.json
npm run dev        # Serveur de développement
npm run build      # Build de production
npm run test       # Tests

# Certains scripts ont des raccourcis
npm start          # Équivaut à npm run start
npm test           # Équivaut à npm run test
```

### Gestion de projet

```bash
# Créer un nouveau package.json
npm init
npm init -y  # Avec valeurs par défaut

# Mettre à jour les dépendances
npm update

# Désinstaller un paquet
npm uninstall react-router-dom

# Lister les paquets installés
npm list
npm list --depth=0  # Seulement le niveau racine
```

### Utilitaires npx

**npx** permet d'exécuter des paquets npm sans les installer globalement :

```bash
# Créer un projet Vite (sans installer create-vite)
npm create vite@latest
# Équivaut à : npx create-vite@latest

# Exécuter un outil temporairement
npx eslint .
npx prettier --write .
```

## En résumé

<Callout type="info" title="Ce que vous devez retenir">
**Node.js :**
- Runtime JavaScript qui tourne hors du navigateur
- Nécessaire pour utiliser npm et les outils de build
- Pas nécessaire en production (seulement pour le développement)

**npm :**
- Gestionnaire de paquets (installé avec Node.js)
- Permet d'installer React et toutes les bibliothèques JavaScript
- Gère les dépendances via `package.json`

**Alternatives :**
- **pnpm** : Plus rapide et économe que npm
- **Yarn** : Alternative populaire
- **Bun** : Le plus récent et rapide, inclut tout (runtime + package manager)

**Commandes de base :**
- `npm install` : Installer les dépendances
- `npm run dev` : Lancer le serveur de développement
- `npm run build` : Créer le build de production
</Callout>
