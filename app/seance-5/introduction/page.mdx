# Introduction - Seance 5

Bienvenue a la derniere seance de ce cours ! Cette seance synthetise tout ce que vous avez appris et vous guide dans la construction d'une application React complete.

## Vue d'ensemble

Cette seance est **differente** des precedentes :
- Moins de nouveaux concepts theoriques
- Plus de pratique et d'application
- Focus sur le workflow avec l'IA
- Construction d'un projet complet de A a Z

<Callout type="info" title="Objectif de la seance">
A la fin de cette seance, vous aurez construit une application React complete, deployee en production, en utilisant toutes les competences acquises durant ce cours.
</Callout>

## Recapitulatif du cours

Avant de commencer, recapitulons ce que vous avez appris :

### Seance 1 : JavaScript ES6+
- Variables et fonctions (const, let, arrow functions)
- Methodes de tableaux (.map(), .filter(), .reduce())
- Destructuration et spread operator
- Async/await et Promises

### Seance 2 : Introduction a React
- JSX et composants
- Props et composition
- Creation de projets avec Vite
- Architecture de base

### Seance 3 : Interactivite
- useState pour la gestion d'etat
- Evenements et handlers
- Formulaires controles
- Rendu conditionnel

### Seance 4 : Effets et Routing
- useEffect pour les side effects
- Fetch API et appels API
- React Router pour la navigation
- Gestion du cycle de vie

## Ce que vous allez apprendre aujourd'hui

### 1. Workflow avec l'IA
- Utiliser l'IA comme assistant de developpement
- Ecrire des prompts efficaces pour React
- Valider et comprendre le code genere

### 2. Pratiques React
- Design de composants (Single Responsibility Principle)
- Conventions de nommage
- Gestion de l'etat et immutabilite

### 3. Structure de Projet
- Organiser vos fichiers et dossiers
- Separation des responsabilites
- Reutilisabilite du code

### 4. Custom Hooks
- Creer vos hooks pour reutiliser la logique
- Exemples : useFetch, useLocalStorage, useDebounce

### 5. Autres Hooks
- useRef pour les references DOM
- useMemo et useCallback pour l'optimisation

### 6. Debogage
- React DevTools
- Erreurs courantes et solutions

### 7. Deploiement
- Build de production
- Deploiement sur Vercel

### 8. Projet Complet
- Application "Ma Liste de Lecture"
- Implementation guidee etape par etape

## Format de la seance

### Partie 1 : Theorie et Pratiques (1h30)
- Workflow avec l'IA
- Pratiques React
- Structure de projet
- Custom hooks et hooks supplementaires

### Pause (15 min)

### Partie 2 : Pratique Guidee (2h)
- Debogage et deploiement
- Projet guide : Construction etape par etape

## Prerequis

<Callout type="warning" title="Verifications avant de commencer">
- Node.js installe (version 16+)
- Un editeur de code (VS Code recommande)
- Git installe et configure
- Un compte GitHub
- Un compte Vercel (gratuit)
- Les connaissances des seances 1-4
</Callout>

<Callout type="tip" title="L'IA comme outil, pas comme remplacant">
L'objectif de cette seance n'est **pas** de vous apprendre a copier-coller du code d'IA sans comprendre.

C'est de vous montrer comment :
- **Utiliser l'IA** pour accelerer votre developpement
- **Comprendre** ce que fait le code genere
- **Adapter** les solutions a vos besoins
- **Deboguer** quand quelque chose ne va pas

**Vous pilotez, l'IA execute.**
</Callout>
