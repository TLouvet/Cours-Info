## Patterns Essentiels à Retenir

### 1. Fetch au Mount

```javascript
useEffect(() => {
  async function fetchData() {
    const response = await fetch(url);
    const data = await response.json();
    setData(data);
  }
  fetchData();
}, []); // Tableau vide = une seule fois
```

### 2. Fetch Basé sur les Paramètres

```javascript
const { id } = useParams();

useEffect(() => {
  async function fetchData() {
    const response = await fetch(`/api/items/${id}`);
    const data = await response.json();
    setData(data);
  }
  fetchData();
}, [id]); // Re-fetch si id change
```

### 3. Cleanup de Timer

```javascript
useEffect(() => {
  const id = setInterval(() => {
    console.log('Tick');
  }, 1000);

  return () => clearInterval(id); // Cleanup
}, []);
```

### 4. Navigation avec Link

```javascript
import { Link } from 'react-router-dom';

<Link to="/about">About</Link>
<Link to={`/users/${user.id}`}>View Profile</Link>
```

## Erreurs Courantes à Éviter

<div className="space-y-4 my-6">
  <div className="p-4 bg-red-50 dark:bg-red-900/20 border-l-4 border-red-500 rounded">
    <div className="font-semibold text-red-900 dark:text-red-100 mb-2">❌ Oublier les dépendances</div>
    <div className="text-sm text-gray-700 dark:text-gray-300 mb-2">
      useEffect utilise une variable mais ne la met pas dans les dépendances
    </div>
    <div className="text-xs text-gray-600 dark:text-gray-400">
      ➜ Toujours inclure toutes les variables utilisées dans l'effet
    </div>
  </div>

  <div className="p-4 bg-red-50 dark:bg-red-900/20 border-l-4 border-red-500 rounded">
    <div className="font-semibold text-red-900 dark:text-red-100 mb-2">❌ useEffect directement async</div>
    <div className="text-sm text-gray-700 dark:text-gray-300 mb-2">
      useEffect(async () =&gt; &#123;...&#125;) ne fonctionne pas
    </div>
    <div className="text-xs text-gray-600 dark:text-gray-400">
      ➜ Créer une fonction async interne et l'appeler
    </div>
  </div>

  <div className="p-4 bg-red-50 dark:bg-red-900/20 border-l-4 border-red-500 rounded">
    <div className="font-semibold text-red-900 dark:text-red-100 mb-2">❌ Oublier le cleanup</div>
    <div className="text-sm text-gray-700 dark:text-gray-300 mb-2">
      Timers, abonnements non nettoyés causent des fuites mémoire
    </div>
    <div className="text-xs text-gray-600 dark:text-gray-400">
      ➜ Retourner une fonction de cleanup dans useEffect
    </div>
  </div>

  <div className="p-4 bg-red-50 dark:bg-red-900/20 border-l-4 border-red-500 rounded">
    <div className="font-semibold text-red-900 dark:text-red-100 mb-2">❌ Utiliser &lt;a&gt; au lieu de &lt;Link&gt;</div>
    <div className="text-sm text-gray-700 dark:text-gray-300 mb-2">
      &lt;a href="/about"&gt; recharge la page entière
    </div>
    <div className="text-xs text-gray-600 dark:text-gray-400">
      ➜ Utiliser &lt;Link to="/about"&gt; pour la navigation SPA
    </div>
  </div>
</div>
